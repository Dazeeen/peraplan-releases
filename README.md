# PeraPlan — Releases

Download the latest **PeraPlan** APK from [Releases](https://github.com/Dazeeen/peraplan-releases/releases/latest) (Android 13+).

The app checks this repo for updates:
- **`vX.Y.Z` releases** contain the APK (app update — downloaded and installed inside the app; the app restarts).
- **`live-N` releases** contain `peraplan-live.json` (live update — applied while the app is open, no restart).
